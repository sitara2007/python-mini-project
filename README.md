Python Mini Projects---->
This repository contains 3 Python mini-projects developed for pre-mock evaluation.
Projects Included

1. ATM Simulation
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History

 2. Game Project
- Stone Paper Scissors
  OR
- Dice Roll Game
- Random results using "random" module
- Winner shown after each round

 3. Library Management System
- Issue Book
- Return Book
- Track student name
- Track number of days
- Fine calculation system
  
Fine Rules

- 1st Week → ₹10/day
- 2nd Week → ₹20/day
- 3rd Week → ₹60/day
- Continues progressively
